# test-win

clone:リモートリポジトリをローカルリポジトリにコピーすること（クローンを作る）
add:ローカルリポジトリにある、どのファイルの変更履歴を保存するか選択すること
commit:add時に変更履歴の内容を記録すること　原則1作業1commit
push:ローカルリポジトリをリモートリポジトリに同期（アップデート）させること（リモートリポジトリと同じ最新の状態にpullしてないとエラーになる）
pull:リモートリポジトリをローカルリポジトリに同期させること

branch:リポジトリの中で分けて管理することができる機能　別branchではお互いに干渉せず作業できる
marge:別branchを統合すること
checkout:SourceTreeのbranch名をダブルクリックすること

reset:commit後push前であれば、変更を白紙に戻せる
